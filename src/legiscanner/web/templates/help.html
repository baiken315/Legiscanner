About Legiscanner

Legiscanner tracks Virginia General Assembly bills for local government review. It discovers bills matching your organization's tracked topics, fetches full bill data from the LegiScan API, and optionally auto-analyzes bills using a local AI model (Ollama).

Pipeline Controls

↑ Smart Update

Re-fetches only bills whose data has changed since the last pull, using LegiScan's change_hash to detect updates. Quick and efficient. Ideal for daily or weekly checks.

→ Full Refresh

Re-fetches all tracked bills from LegiScan, regardless of changes. Use if data seems out of sync or texts need refreshing. Slower, uses more API calls.

★ Auto-tag New

Sends unanalyzed bills to the local AI model (Ollama) for topic tagging, impact scoring, and relevance reasoning. Only tags new unanalyzed bills. Requires running Ollama.

Filtering & Sorting

Search

Full-text search across bill numbers, titles, descriptions, and AI analysis. Type to filter in real time.

Impact Levels

Filter by AI impact score (1-5). Click badges to toggle. Default shows 2-5; check level 1 to see all bills including low-relevance ones.

Hide Low Relevance

Hides impact-level 1 bills. Unsolved bills (no score yet) are shown regardless.

Watching Only

Shows only bills you've marked as 'watching' (star icon).

Tags

Filter by AI or manually added topic tags. Bills matching any selected tag are shown.

Bill Numbers

Jump to specific bills by comma-separated numbers (e.g., HB1234, SB567).

Bill Detail Modal

Click any bill card to open a detailed view with these tabs:

  • Overview — Summary, tracking info, sponsors, history, external links
  • Bill Text — Full text with version selector and copy button
  • Legislative Assistant — Chat with Ollama AI about bill implications, preemption risk, political dynamics. Responses can be added to bill notes.
  • Lineage — Shown only when the bill is part of a cross-session lineage; a timeline of the same bill across sessions with a link to the full lineage.

Bulk Actions

  • Watch All / Unwatch All — Toggle watching status in bulk
  • Apply Tag / Create & Tag — Add existing or new tags to all filtered bills
  • Delete Tag — Remove a tag from all filtered bills
  • Export CSV — Download filtered bills with chosen columns

Impact Scores

AI scores each bill 1-5 on significance for local government:

Score Color Meaning
1 1 Minimal impact on local government
2 2 Minor impact
3 3 Moderate impact
4 4 High impact
5 5 Critical impact

Companion Bills

Legiscanner auto-detects companion bills (HB/SB pairs with similar titles) within a session. A &d8; icon indicates companion bills. Click links in the detail modal to view.

Bill Lineages (Cross-Session)

A lineage groups the same (or same-subject) bill as it is re-introduced across legislative sessions — the cross-session counterpart to companion bills. Lineages are detected from cross-session title similarity and shared LegiScan bill IDs, and re-computed with: 

legiscanner link-lineages --db legiscanner.db
  • Lineages in the header → /lineage lists every lineage; click one to see how it evolved session over session.
  • ↻ indicator on a bill card — the bill is in a multi-bill lineage; click it to open the lineage timeline.
  • Lineage tab in the bill detail modal — timeline of the bill's cross-session history.

Lineages only appear once the database holds bills from more than one session.

Sessions

One database spans every legislative session you track. The session switcher at the top of the bill list lets you browse any session (and set one as the active default for pipeline runs). The --session flag on CLI commands (discover, sync-session, autotag, export-text, link-companions) targets a specific session instead of the active one. Use legiscanner sessions-local to list the sessions in your database.
